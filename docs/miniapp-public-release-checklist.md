# 公开小程序提审清单

公开版产品名建议使用“个人复盘助手”，定位为用户主动填写计划、实际结果并查看个人历史统计的工具。`miniapp-public` 是唯一用于微信公开审核和发布的目录；`miniapp` 保留为个人自用研究版，两者不得混合上传。

## 提交前必须完成

- 微信公众平台中的小程序名称、简介、头像和截图均使用个人记录工具定位。
- 服务类目选择与实际功能一致的工具类目，并以微信公众平台当时可选类目为准。
- 隐私保护指引如实填写 OpenID 登录、订单信息、客服核对和删除方式。
- 体验账号可以完成微信快捷登录、新增记录、编辑记录、删除记录、历史统计和注销账号。
- 开发版、体验版和正式版只连接独立云托管服务 `fupanbiji`，该服务必须设置 `MINIAPP_PRODUCT_MODE=personal_records`。
- 运行 `python scripts/check_public_miniapp_compliance.py`，结果必须通过。
- 微信开发者工具执行代码质量检查、真机预览和体验版回归，不得有接口失败或空白页。

## 公开版禁止内容

- 具体投资品种的筛选、排序、评价、预测或方向判断。
- 任何买卖时机、价格区间、目标、风险阈值或自动操作提示。
- 实时价格图、市场热度、资金流、榜单、模拟下单或自动交易。
- 用会员、课程、社群、增值服务等名义间接收费提供上述能力。
- “必然、保证、稳定获利”等结果承诺。

## 增值服务上线门槛

增值服务只能对应通用工具能力，例如云端备份、多设备同步、历史记录导出和个人长期统计。在以下事项全部完成前，`MINIAPP_PAYMENT_LIVE_ENABLED` 必须保持为 `false`：

- 个人主体虚拟支付资格在微信公众平台审核通过。
- OfferID、正式 AppKey 和全部服务期道具已配置并发布。
- 服务端订单使用持久化数据库，已完成下单签名、回调验签、幂等发货和定时查单。
- 安卓与 iOS 的小额真单、退款、重复通知和超时恢复均通过验收。
- 购买页、退款说明、客服能力和价格与平台后台配置完全一致。

## 保留边界

PC 端和个人自用研究版可以继续独立开发，但不得通过公开小程序、付费链接、会员权益或客服消息向他人提供具体投资建议。若未来希望公开提供证券投资咨询能力，应先由专业律师核验业务模式，并取得监管和平台要求的全部资质。
