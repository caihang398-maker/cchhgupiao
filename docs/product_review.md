# 产品走查与迭代路线

## 当前定位

本系统适合定位为“面向普通投资者的可解释 A 股每日研究助手”，核心价值是：

- 将全市场资金、估值、现金流、分红、热点和 K 线信号组合成不超过30只候选。
- 直接给出推荐原因、风险位、卖出条件和仓位，而不是只展示指标。
- 支持股票名称或代码查询，使用门槛低于专业量化开发平台。
- 每次扫描和分析结果可落库，适合后续做推荐复盘和 SaaS 账号管理。

它不适合宣传为“必涨预测”或“自动赚钱系统”。产品可信度应主要来自可复现的历史结果、数据质量说明和风险控制。

## 已完成

1. 新增独立“名词与方法”页面，解释筛选条件、指标、评分、数据口径及回测边界。
2. 实时成交量统一换算为“手”，修复与历史 K 线成交量相差100倍的问题。
3. 买点与止损之间增加风险缓冲，不再出现两者完全相同。
4. 技术面不足、建议仓位为0的股票不再进入新推荐池。
5. 个股页接入历史回测，使用下一交易日开盘成交、100股整数手、佣金最低收费、卖出印花税和滑点。
6. 回测增加基准收益、最大回撤、夏普、胜率、盈亏比和成交记录。
7. 页面导航改为可扩展结构，为后续按角色显示管理员和会员页面做准备。
8. 推荐结果自动计算推荐后1日、5日、20日收益、目标/止损命中和收盘最大回撤。
9. 每次扫描保存策略版本和参数快照，复盘页面可按版本筛选。
10. 已接入可配置的 MySQL 登录、会员到期校验、管理员开通、续费、停用和审计记录。
11. SQLite 已启用外键、WAL并发模式和明确关闭连接，并增加在线备份及发布前自检脚本。
12. 图表日期、后台状态、角色、数据列和命令行提示已统一为中文。

## 发布后优先级

### P0：正式商业运营前仍需确认

- 数据质量中心：进一步展示每个数据源的精确更新时间、覆盖率、失败项和降级来源。
- 故障告警：计划任务、备份或数据源连续失败时主动通知管理员。
- 商业合规与数据授权审查：确认行情、财务、资讯数据的商业使用许可，并由专业人士评估产品宣传和服务边界。
- MySQL 5.7 和 Windows Server 2016 已进入较晚支持阶段，新部署优先评估仍受支持的版本。

### P1：提升付费价值

- 自选股与模拟组合：记录成本、仓位、浮盈亏、风险暴露和调仓建议。
- 推荐订阅：按行业、题材、短中长期和风险等级分别推送。
- 财报与公告事件：业绩预告、减持、解禁、问询、重大合同和停复牌风险提示。
- 推荐归因：解释当日评分相对昨日为何上升或下降。
- 行业横向对比：市盈率、市净率、净资产收益率、现金流、资金流在行业中的分位数。
- 参数模板：稳健、均衡、进取三套配置，避免普通用户随意调参造成误解。

### P2：专业量化能力

- 因子 IC、分层收益、换手率和因子相关性分析。
- 滚动样本外验证、参数敏感性和过拟合风险检查。
- 多策略组合、行业中性、仓位优化和组合最大回撤控制。
- 模拟交易和券商接口，但必须先完善风控、权限、审计和合规。

## 建议的产品主线

不要以“更多指标”作为主要竞争方向。下一阶段最值得做的是：

1. 证明过去推荐表现如何。
2. 清楚解释今天为什么推荐。
3. 明确什么情况下不应该买。
4. 让用户能管理自己的观察池和模拟组合。
5. 让管理员能可靠地管理账号、到期、数据和任务。
